# macOS automation

Build automations for Mail, Calendar, Notes, and Reminders with JXA, AppleScript, Swift, and EventKit.

## Skills

| Skill | Scope |
| --- | --- |
| `macos-automation-core` | Runtime choice, permissions, error handling, and TypeScript wrappers. |
| `mail-automation` | Read, search, draft, and send with Mail.app. |
| `calendar-automation` | Read, create, update, and search Calendar events. |
| `notes-automation` | Read, search, and create Notes. |
| `reminders-automation` | Use EventKit from Swift for full Reminders access. |
| `macos-automation-builder` | Design and implement single-app or cross-app automations. |

The generated Claude Code adapter includes an `automation-builder` agent that loads the portable builder skill.

macOS privacy permissions still apply. Grant the launching client access under System Settings > Privacy & Security before running an automation.
