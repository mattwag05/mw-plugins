# i-have-adhd

Shape responses so an ADHD reader can find and act on the next step. The skill leads with action, numbers multi-step work, keeps state visible, limits tangents, and removes routine preambles and closers.

Invoke `/i-have-adhd` to start the mode and say `stop adhd mode` to stop it. The Claude Code adapter also keeps the upstream opt-in session hook. Create `.i-have-adhd-always` under the Claude configuration directory to enable that hook.
