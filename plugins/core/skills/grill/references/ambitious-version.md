# The ambitious version

Read this when the human asks to aim higher. It condenses the retired `ambition` skill, which paraphrased Felix Rieseberg's post "How to be more ambitious: A tutorial for humans with models" (13 October 2026). Pick the axes that fit; you rarely need all three. Doing the same work faster is not an axis.

## Outcome first

Restate the task in one line, then answer: what does the human want to happen after this is done? That answer is the `Outcome:` line.

## Altitude: own the result, not the task

"Fix this crash" becomes "keep the app crash-free." Climb in steps, each one usable on its own:

1. Explain: read all the raw material and say what changed, why, and what to do about it.
2. Decide: name the few decisions that matter now, with options and the case for and against each.
3. Redesign: propose a better format, test it against the human's own history, and run it beside the old process before replacing it.

Pick the highest outcome you can measure and check. List what you would need to pursue it without a human feeding you tasks (data feeds, access, machines to reproduce on), and say which exist.

## Depth: work like the field's best practitioner

- Use their instruments: load the database, fit the model, run the profiler. Name the tools.
- Start from raw material (logs, source data, primary records), not summaries.
- Set a specific hard target as a number (200 ms, not "faster").
- Test what everyone believes: try to reproduce the stated assumption from the data, and report where it fails.
- Get an outside judge: a test suite, benchmark, held-out data, compiler, or another system's output.

To deepen a prompt instead of running it, answer: what would a top professional do that the prompt does not ask? What raw material would they start from? Which methods and tools? What, other than you or the human, would show the result is right? Then rewrite the prompt at about its original length.

## Range: borrow other fields' methods

- Describe the work as a verb: a quarterly deck is "getting busy people to believe a cause-and-effect story and decide in 30 minutes." The verb shows which fields can help.
- Name the crew you would hire, including a red team (a short seller, a forensic accountant).
- Do each field's actual work, not role play: a short seller finds the weakest number and checks it against outside sources.
- Where the platform allows, give each field its own subagent with a concrete method, then merge.

## Limits

Ambition changes scope. Present the upgraded plan and wait for a yes before acting. It never widens authorization: pushes, deploys, messages, access, and spending each still need the human's own words.
