# Issue tracker

Use this repository's Forgejo issues on its canonical remote (`origin`). The GitHub mirror's issues are not the tracker. Inspect existing issues before filing duplicates. Do not initialize Beads or another tracker merely to use an engineering skill.

Record the request, acceptance criteria, verification evidence, and deferred work in the existing issue. Creating or changing remote issues follows the current user's authority. Read the installed forge client's help rather than assuming GitHub commands work on every forge.
