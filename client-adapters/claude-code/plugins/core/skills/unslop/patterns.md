# Patterns to find and fix

Read this when editing existing prose. Each line gives the tell, then the fix.

## Content
- Significance inflation ("pivotal moment", "testament to", "evolving landscape", "setting the stage"): state what happened.
- Promotional words ("vibrant", "groundbreaking", "stunning", "renowned", "nestled"): neutral description.
- Vague attribution ("experts believe", "studies suggest"): name the source or delete.
- Trailing -ing phrases ("highlighting...", "ensuring...", "showcasing..."): delete, or give the real reason.
- Formulaic challenge arcs ("Despite challenges... continues to thrive"): specific facts.
- Generic conclusions ("the future looks bright"): a concrete next step or nothing.

## Language
- AI vocabulary: delve, crucial, pivotal, tapestry, intricate, garner, underscore, testament, landscape (abstract), foster, showcase, seamless, robust, leverage (verb), utilize. Use the plain word.
- Copula avoidance ("serves as", "boasts", "features"): write "is" or "has".
- Negative parallelism ("it's not just X, it's Y"): state Y.
- Forced groups of three: use the real number of items.
- Synonym cycling (one thing named four ways): pick one name and repeat it.
- Abstract metaphor nouns (substrate, vector, nexus, paradigm, scaffolding): use the concrete word.

## Style
- Em dashes: never. Use a period, comma, or parentheses.
- Colons as mid-sentence connectors: rewrite as two sentences. A colon before a list is fine.
- Bold on every term, bold-label lists that restate the line, Title Case Headings, decorative emoji, curly quotes: remove or use sentence case and straight quotes.

## Chat artifacts and filler
- "Great question", "Certainly!", "I hope this helps", "Let me know if": delete.
- "In order to" becomes "to". "Due to the fact that" becomes "because". "It is important to note that": delete.
- Stacked hedges ("could potentially perhaps"): one "may", or commit.
- "In today's fast-paced world", "in the ever-evolving": delete the sentence.
- Adverbs propping a weak verb ("significantly improves"): use the measured number or a stronger verb.

## Structure
- Dense sentences: split so each carries one idea.
- Passive voice that hides the actor: name the actor.
- Frame last, point first ("Mail was the hard part"): put the frame first, the specific thing last ("The hardest part was Mail.").
- Labels: use the term readers already know. Name items in a set the same way (all goals, or all categories).

## Additions from the retired unslop and i-have-adhd skills
- Name-dropping a list of outlets or people with no context: pick one and say what it said.
- False ranges ("from X to Y" where X and Y are not on one scale): list the items.
- Knowledge-cutoff disclaimers ("While specific details are limited..."): find a source or cut it.
- En dashes or spaced hyphens used as an em dash: same fix as the em dash.
- More AI vocabulary: additionally, enhance, enduring, interplay. More abstract nouns: wedge, locus, vantage, primitive (noun), surface ("API surface"), bedrock, modality, gold-plating.
- Idioms ("circle back", "get the ball rolling", "on the same page"): write the literal action.
- A first sentence that announces what comes next ("Let me...", "I'll..."): delete it and start with the answer.
- Empty hedges ("perhaps", "could possibly"): delete. Keep a hedge that carries real uncertainty.
- Voice: use "I" where it fits, and say so when a reaction is mixed ("fast, but the setup is fiddly").
