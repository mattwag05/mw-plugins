# Archived plugins

Retired 2026-11-15 when the core skill set replaced them. They are kept for history and for ideas; nothing installs them.

| Plugin | Where its ideas went |
| --- | --- |
| `autonomous-execution` | `core/LOOP.md` (stop after 3 distinct approaches) and `core/AGENTS.md` (run a check yourself before asking the human; verify an approved action yourself). Its command cookbooks were dropped. |
| `ambition` | `core/LOOP.md` Verify step 3 (judge success by a check that does not depend on you). The altitude, depth, and range method was too long for small models. |
| `i-have-adhd` | Dropped. Reply-shape rules are a taste choice; `closeout` and `handoff` already end with one next step. |
| `phased-shipping` | `plan` (verifiable slices, issues with blockers) and `ship-ready` (PR body). Host-specific PR mechanics were dropped. |
| `project-housekeeping` | `closeout` and the `core/AGENTS.md` rule to look at a target and prefer reversible deletes. |
| `session-closeout` | `closeout`. |
| `unslop` | Core `unslop` (rules, `patterns.md`, and `scripts/slop_scan.py`). |
| `internet-skill-finder` | Dropped: a fixed index of repositories with stale star counts. |
