# Archived plugins

Retired 2026-11-15 when the core skill set replaced them. They are kept for history and for ideas; nothing installs them.

| Plugin | Where its ideas went (folded 2026-11-15, see `core/AGENTS.md` "Retired skill names") |
| --- | --- |
| `autonomous-execution` | `core/AGENTS.md` Behavior (run a check yourself before asking; verify an approved action yourself) and `core/LOOP.md` Do (stop after 3 distinct approaches) and Verify (check what the human would check; no homework). Its command cookbooks were dropped. |
| `ambition` | `grill`, section "Aim higher", with `grill/references/ambitious-version.md`. |
| `i-have-adhd` | `unslop`, section "Replies", and the Writing rule in `core/AGENTS.md`. The on/off mode was dropped. |
| `phased-shipping` | `plan` (premise check, one PR per slice) and `ship-ready` (outgoing commits, CI gate, `references/stacked-prs.md`). Auto-push, polling, and `/simplify` steps were dropped. |
| `project-housekeeping` | `closeout` and `closeout/references/housekeeping.md`. |
| `session-closeout` | `closeout`, `closeout/references/housekeeping.md`, and `ship-ready` for the push ask. |
| `unslop` | Core `unslop` (rules, `patterns.md`, and `scripts/slop_scan.py`). |
| `internet-skill-finder` | Dropped: a fixed index of repositories with stale star counts. |
